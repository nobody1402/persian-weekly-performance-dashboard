# داشبورد گزارش هفتگی

یک داشبورد مدیریتی فارسی و راست‌به‌چپ برای پایش اهداف سازمان، گزارش‌های هفتگی و تحلیل عملکرد واحدها.

## امکانات پیاده‌سازی‌شده

این نسخه شامل داشبورد اصلی با کارت‌های KPI، روند هشت‌هفته‌ای پیشرفت، مقایسه واحدها و نمودار وضعیت اهداف است. بخش‌های مدیریت اهداف، گزارش هفتگی، تحلیل عملکرد، گزارش مدیریتی و مقایسه هفتگی نیز از طریق منوی کناری در دسترس هستند.

تعامل‌های اصلی شامل جست‌وجو و فیلتر اهداف، باز کردن جزئیات هدف، نمایش تاریخچه پیشرفت، تکمیل اقدامات بعدی، حذف هدف، افزودن هدف جدید، ثبت گزارش با اعتبارسنجی Zod، اعلان‌ها و آماده‌سازی خروجی گزارش فعال هستند. داده‌های نمونه در ماژول مشترک `shared/dashboard.ts` نگهداری می‌شوند تا اتصال بعدی به API یا پایگاه‌داده ساده باشد.

## راه‌اندازی محلی

پروژه با قالب Full-stack وب‌دِو Manus اجرا می‌شود و از React، Vite، TypeScript، Tailwind CSS، Express، tRPC، Drizzle و Recharts استفاده می‌کند.

```bash
pnpm install
pnpm dev
```

برای بررسی کیفیت کد و ساخت نسخه تولیدی:

```bash
pnpm check
pnpm test
pnpm build
```

## ساختار مهم پروژه

| مسیر | کاربرد |
| --- | --- |
| `client/src/pages/Home.tsx` | رابط اصلی داشبورد و صفحات داخلی |
| `shared/dashboard.ts` | مدل‌های دامنه، داده‌های نمونه و قرارداد اعتبارسنجی |
| `shared/dashboard.test.ts` | تست‌های اعتبارسنجی گزارش هفتگی |
| `drizzle/schema.ts` | نقطه شروع مدل‌سازی جداول پایگاه‌داده |
| `server/routers.ts` | محل افزودن قراردادهای tRPC برای API واقعی |
| `todo.md` | وضعیت قابلیت‌ها و کارهای بعدی |

## اتصال به GitHub

در پوشه پروژه یک مخزن Git ایجاد شده است. برای انتشار در مخزن GitHub خود، ابتدا یک repository خالی در GitHub بسازید و سپس این دستورات را اجرا کنید:

```bash
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git add .
git commit -m "Build Persian weekly performance dashboard"
git branch -M main
git push -u origin main
```

مقدار `USERNAME/REPOSITORY` را با نام حساب و مخزن خود جایگزین کنید. فایل‌های محیطی و secrets را به Git اضافه نکنید.

## یادداشت فنی

اسکفولد موجود به‌صورت React/Vite + Express/tRPC ارائه شده است؛ بنابراین پروژه بر اساس قابلیت‌های واقعی همین قالب پیاده‌سازی شده و به جای فرض‌کردن Next.js، از معماری فعال و قابل اجرای پروژه استفاده می‌کند. لایه داده اکنون با داده نمونه کار می‌کند و برای اتصال به جداول اهداف، گزارش‌ها، اقدامات و اعلان‌ها آماده است.
